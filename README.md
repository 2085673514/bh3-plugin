# bh3-plugin 崩坏3全功能查询插件（个人自用改版）

> **个人自用改版**：本仓库基于 [QWEfcxzz/bh3-plugin](https://github.com/QWEfcxzz/bh3-plugin) 修改，玩家卡片 / 战报 / 手帐 / 补给与道具记录等功能由 [chingkingm/honkai_mys](https://github.com/chingkingm/honkai_mys) 迁移而来。仅作个人自用，不保证稳定性，也不一定跟进上游更新。

面向 Yunzai / TRSS-Yunzai 的崩坏3（Honkai Impact 3rd）查询插件，支持战绩查询与公开图鉴查询。

## 图片输出

所有查询结果均以图片卡片形式输出（粉紫渐变 + 磨砂玻璃风格）：

- 深渊 / 记忆战场 / 往世乐土：角色大头像 + 名字 + 星级卡片展示阵容
- 角色面板：仿喵喵插件原神面板的大头像 + 武器/圣痕/人偶装备卡 + 六维评价
- 有链接的结果（WIKI 等）会在图片后附带可点击的链接文本

## 出图参数

图片默认以 JPEG 输出，可用环境变量调整（改完重启 Bot 生效）：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `BH3_IMAGE_SCALE` | 1 | 出图倍率乘数，越小图越小（建议 0.5–1.5） |
| `BH3_IMAGE_QUALITY` | 0（不覆盖） | JPEG 质量上限（1–100，只降不升） |
| `BH3_IMAGE_WAIT_MS` | 4500 | 等待远程图片加载的毫秒数 |
| `BH3_IMAGE_MAX_BYTES` | 2097152 | 单图体积上限，超过会自动降质重截 |
| `BH3_IMAGE_SAVER` | 0 | 设为 1 开启省流模式（倍率 ×0.8、质量 ≤75、体积 ≤1.2MB） |

例：`BH3_IMAGE_SAVER=1` 适合弱网或小群；`BH3_IMAGE_SCALE=1.2` 可让字更清晰。

## UID 绑定方式

支持两种绑定方式，均可直接查询：

1. **米游社 Cookie 自动绑定（honkai-mys 方式，推荐）**：先发送 `#绑定Cookie` 登录米游社账号，之后无需 `#崩坏3绑定`，直接发送 `#崩坏3面板` 等命令会自动使用该账号的崩坏3角色（UID 与服务器自动解析）。
   也可发送不带参数的 `#崩坏3绑定`，插件会按 Cookie 账号自动写入绑定。
2. **手动绑定**：`#崩坏3绑定 <UID>` / `#崩坏3切换 <UID>`，使用 `#崩坏3当前` 查看、`#崩坏3解绑` 解除。

所有战绩命令也支持临时附加 UID（如 `#崩坏3面板 100000001`），优先级：显式 UID > 手动绑定 UID > Cookie 账号。

## Cookie 来源（优先级）

1. `#崩坏3cookie <UID> <Cookie>` 配置的专用 Cookie
2. `#崩坏3cookie <Cookie>` 配置的公共 Cookie
3. **yunzai 已绑定 Cookie（`#绑定Cookie`）中拥有该 UID 的账号 CK**
4. **逍遥插件（xiaoyao-cvs-plugin）已获取的 CK** —— 自动从共享数据库读取，使用拥有该 UID 的账号 CK（仅 Bot 主人可以使用，避免群友借 UID 查他人账号）

## 重要限制

米游社崩坏3战绩接口**仅允许查询 Cookie 所属账号本人的号**（跨账号查询会返回“用户信息不匹配”）。因此：

- 群友想查自己的面板：先用 `#绑定Cookie` 或逍遥插件登录自己的米游社账号（该号需有崩坏3角色），之后直接发 `#崩坏3面板`（或自己的 UID）即可查询，无需在崩坏3插件里配置任何东西。
- 无法查询其他人的号（官方接口限制，非插件限制）；`#崩坏3手帐@某人`、`#崩坏3抽卡记录@某人` 这类查询也仅 Bot 主人可用。
- 若目标 UID 没有对应已登录的米游社账号，插件会明确提示原因。

## 角色数据库

插件内置女武神数据库（来自米游社公开图鉴，`data/characters.json`，数量随图鉴自动更新），每名角色包含：

- 别名（如 炎律→薪炎之律者、黑希→彼岸双生、火符→浮生·渡尘之羽）
- 元素（物理/火/冰/雷）、属性（生物/异能/机械/量子/虚数/星尘）、初始阶级
- 角色立绘（竖版）、背景图（横版）、头像
- 六维评价（持续输出/爆发输出/爆发速度/控制/生存/辅助）

所有支持角色的命令（角色图、伤害计算、角色面板、图鉴）都支持别名匹配。

## 伤害计算说明

`#崩坏3伤害` 使用简化公式估算：

```
伤害 = 攻击力 × 技能倍率 × (1+增伤) × (1+易伤) × (1-抗性) × 暴击期望
物理角色额外乘 (1 - 防御/(防御+2000))
```

默认参数：倍率 100%、增伤 0%、暴击率 100%、暴伤 150%。结果为估算值，未计入队友增益、易伤、穿透与实际技能倍率，请以游戏内为准。

## 帮助图

`#崩坏3帮助` 会渲染一张爱莉希雅（粉色妖精小姐♪）主题的帮助图：横版立绘为背景、竖版立绘作装饰，命令按模块分类展示。渲染结果按 HTML 内容哈希缓存到 `data/bh3/help-<hash>.jpg`，内容不变时直接复用；若本机 Puppeteer 渲染失败会自动回退为纯文本帮助。

## 性能与安全（本改版）

- **共享 Chromium**：帮助图、角色卡片、记录卡片共用一个浏览器实例，不再每次出图都冷启动/关闭 Chromium。
- **小体积出图**：所有卡片默认输出 JPEG（按内容选 85/88 质量），图片体积约为 PNG 的 1/4~1/5，长图会再降一档质量兜底，避免群图发送超限、加载缓慢。
- **帮助图缓存**：按内容哈希缓存，命中后不再启动浏览器；缓存文件保留最近 3 份、7 天后清理。
- **请求重试**：米游社接口遇到 429 / 5xx / 网络错误会退避重试，并遵守 `Retry-After`；图鉴接口同样接入重试。
- **图鉴缓存**：搜索缓存 5 分钟、详情缓存 6 小时，重复查询不再打接口。
- **套装索引**：看过的圣痕套装会记录到 `data/bh3/wiki-sets.json`，之后可直接按套装名搜索。
- **Cookie 不进日志**：`#崩坏3cookie` 规则关闭消息日志，且只允许私聊提交，回显仅显示脱敏 UID。
- **凭据落盘**：`data/bh3/*.json` 使用 0600 权限 + 临时文件原子替换；解析失败会先备份为 `*.corrupt-<时间戳>` 再重建。
- **记录压缩**：`data/honkai-mys/**/*.jsonl` 超过 5 MB 时自动去重压缩，避免无限增长。
- **越权防护**：共享数据库 CK 与 @他人 查询仅 Bot 主人可用。

## 周常参与提醒（可选）

在**深渊结算前 1.5 小时**检查深渊、**周日 08:00** 检查战场 / 乐土；本期没参与时私聊提醒 Bot 主人（不再 @ 群成员）：

```
#崩坏3推送 状态

#崩坏3推送 UID 100000001
#崩坏3推送深渊               # 查看深渊提醒设置
#崩坏3推送深渊 22:00         # 超弦空间结算时间（提醒在结算前 1.5 小时）
#崩坏3推送深渊 开启|关闭      # 单独开关深渊提醒
#崩坏3推送战场/乐土           # 查看战场/乐土提醒设置
#崩坏3推送战场/乐土 08:00     # 周日检查时间
#崩坏3推送战场/乐土 开启|关闭  # 单独开关战场/乐土提醒
#崩坏3推送 测试            # 立即检查一次并发送提醒
#崩坏3推送 关闭
```

- 超弦空间：周一/周四 15:00 开放，**周三 / 周日 22:00 结算**；提醒在**周三、周日 20:30** 检查深渊本期是否参与。
- 记忆战场 / 往世乐土：以**周一 04:00** 周重置为界，**周日 08:00** 检查本周是否参与。
- 参与判定：最新战绩时间晚于本期起点即视为已参与；同一检查点最多尝试 3 次，成功后不再重复，结算后不再提醒。
- 深渊提醒与战场/乐土提醒可分别开关：`#崩坏3推送深渊 关闭`、`#崩坏3推送战场/乐土 开启`。
- 只提醒 Bot 主人私聊；UID 必须已绑定 Cookie（私聊发送 `#崩坏3cookie <uid> <cookie>`）。
- 配置保存在 `data/bh3/push.json`，运行状态在 `data/bh3/push-state.json`。
- 也可用环境变量 `BH3_PUSH_ENABLED` / `BH3_PUSH_ABYSS` / `BH3_PUSH_WEEKLY` / `BH3_PUSH_UID` / `BH3_PUSH_SUNDAY_TIME` / `BH3_PUSH_SETTLE_TIME` 覆盖。

## 数据来源

- 战绩查询：米游社崩坏3 战绩接口（`api-takumi-record.mihoyo.com/game_record/app/honkai3rd/api`），需要绑定米游社 Cookie。
- 图鉴查询：米游社崩坏3 公开图鉴接口（`api-takumi-static.mihoyo.com/common/blackboard/bh3_wiki`），无需 Cookie。

## Cookie 获取

1. 浏览器登录 https://www.miyoushe.com
2. F12 打开开发者工具，在 Network 中找到任意请求，复制请求头中的完整 `Cookie` 字段值
3. **私聊**对 Bot 发送 `#崩坏3cookie <粘贴的Cookie>`（仅主人可用；插件会拒绝群聊提交，避免凭据进群和日志）

> 注意：Cookie 包含账号凭据，仅建议主人在自己的机器人上配置，不要泄露给他人。米游社可能对频繁请求触发验证码风控（retcode 1034），此时请稍后再试。

## 安装

### 方式一：Git 克隆（推荐）

在 Yunzai 根目录执行：

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git ./plugins/bh3-plugin
```

### 方式二：手动解压

将压缩包解压到 Yunzai 的 `plugins/bh3-plugin` 目录。

### 安装依赖

进入插件目录安装依赖（任选一种）：

```bash
cd plugins/bh3-plugin
npm install
```

或使用 pnpm：

```bash
cd plugins/bh3-plugin
pnpm install
```

依赖说明：

- `sqlite3`：读取逍遥插件（xiaoyao-cvs-plugin）/喵喵共享数据库中的米游社 CK，实现"群友只发 UID 即可查询自己的面板"（共享 CK 仅 Bot 主人可用）。未安装时插件仍可用，但只能通过 `#崩坏3cookie` 手动配置 Cookie。
- `puppeteer`（可选）：用于渲染帮助图与各类卡片。未安装时 `#崩坏3帮助` 自动回退为纯文本，卡片类命令提示制图失败。

要求 Node.js >= 18（插件使用全局 `fetch`）。

最后重启 Bot 即可使用。

## 角色数据库（自动更新）

`data/characters.json` 是女武神数据库，插件会自行维护，一般不需要手动处理：

- **启动后自动检查**：文件缺失、损坏，或超过 **7 天**未更新时，启动约 10 秒后在后台从米游社图鉴重新抓取全部女武神（约 110 次请求，耗时半分钟左右）。抓取完成后立即生效，无需重启，也不会阻塞 Bot 启动。
- **失败不破坏数据**：网络异常或抓取数量明显偏少时保留原文件，只记一条 warn 日志，插件其余功能不受影响。
- **运行期间复查**：每 24 小时（每天）检查一次，长期不重启的 Bot 也能自动收录新角色。

需要立刻更新时（比如新版本刚上线），二选一：

```bash
cd plugins/bh3-plugin
npm run update:data
```

或在聊天中由主人发送 `#崩坏3更新角色库`，返回的提示会说明抓取数量与失败条数。

可调参数（环境变量）：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `BH3_CHARACTER_AUTO_UPDATE` | `1` | 设为 `0` / `false` 关闭启动自动更新 |
| `BH3_CHARACTER_MAX_AGE_DAYS` | `7` | 数据库超过多少天视为过期 |
| `BH3_CHARACTER_STARTUP_DELAY_MS` | `10000` | 启动后延迟多久开始检查 |
